# NV: Скриншоты Warspear Online

Проект для автоматического захвата скриншотов окна игры Warspear Online с использованием YOLOv8 и PyQt5. Подготовка будущего датасета для модели компьютерного зрения.

## Особенности
- Захват скриншотов окна игры.
- Автоматическое изменение размера окна игры.
- Сохранение скриншотов в формате PNG.
- Логирование событий в интерфейс и консоль.
